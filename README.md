# 安心超级卫士（ParentSuperGuard v5.6）

专为长辈（非 Root、免 Shizuku 的小米 / vivo / OPPO / 华为 / 荣耀等手机）设计的**零联网、无广告、铁壁防误删**清理与防流氓助手。

## 一、给家长看的 3 步日常用法

1. 打开桌面的绿色盾牌图标 **「安心超级卫士」**。
2. 点击首页大大的绿色按钮 **「一键安全清理高缓存软件」**。
3. 稍等半分钟，看到绿色完成提示后即可正常使用（微信聊天记录、照片、视频与手机银行全部绝对保护，一条不动）。

> 微信瘦身请点首页「看 3 步清微信」走微信官方自带的「我 → 设置 → 通用 → 存储空间 → 清理缓存」，绝不私自碰微信目录。

## 二、子女首次帮家长配置（约 2 分钟）

1. **开启「使用情况权限」**（必须）：点击首页第 1 步橙色按钮，找到「安心超级卫士」打开开关。开启后软件才会精准筛出缓存大于 5 MB 的大户软件，未开启前主清理按钮自动锁定，防止误把全机几十个软件挨个翻页吓到家长。
2. **解锁新系统「受限设置」**（小米澎湃OS / vivo OriginOS 等 Android 13+ 机型）：若无障碍开关变灰，点首页「2 步解锁」打开本软件应用信息 → 右上角 `⋮` →「允许受限设置」。
3. **核对「已装软件排查」**：打开排查列表确认家长手机上的微信、支付、所有银行 App 均显示 **「铁壁保护」**；若有地方小银行/医院挂号 App 未命中，可在高缓存列表中点「加保护」手动加锁。
4. **推荐防误装设置（零银行风控）**：点首页「直达系统安装未知应用」，把浏览器、抖音、头条等软件的安装未知应用权限全部关掉，从源头挡住流氓软件误装。

## 三、会删什么 / 绝不删什么

* **会安全清理**：抖音、快手、拼多多、淘宝、浏览器等第三方高缓存软件的系统缓存（每次最多清缓存最大的前 20 个）；相册旧预览缩略图（`.thumbnails`）与系统调试日志（`MIUI/debug_log`、`BugReport`、`ramdump`、`vivo_log`）。
* **绝不触碰**：照片、视频、文档、下载文件、家长自建文件夹（已关闭空文件夹自动删除）、微信/QQ/企业微信/钉钉/支付宝/云闪付/数字人民币/国家反诈中心、各大银行与农商行、医保/12306/个税、系统相册与闹钟。
* **隐私与防银行风控**：不申请 `INTERNET` 联网权限，100% 离线无广告；清缓存专用无障碍服务默认清理完毕自动调用 `disableSelf()` 彻底关闭，不触发银行 App 屏幕风险拦截。

## 四、GitHub 自动打包与固定签名升级说明

* 每次推送到 `main` 分支会自动运行单元测试并编译 **已签名 Release APK**（`ParentSuperGuard-vX.X.apk`），在仓库 **Actions → Artifacts** 下载；推送如 `git tag v5.6 && git push origin v5.6` 时会自动挂到右侧 **Releases**。
* **固定签名机制（升级不掉数据）**：
  * **优先使用 GitHub Secrets（长期维护强烈推荐）**：在仓库 `Settings → Secrets and variables → Actions` 配置 `SIGNING_KEY_BASE64`、`SIGNING_STORE_PASSWORD`、`SIGNING_KEY_ALIAS`、`SIGNING_KEY_PASSWORD`，CI 会自动清洗空格/换行并用你的私有证书签名；配好后可删除仓库内的 `app/signing/family-fixed.keystore`。
  * **零配置兜底**：未配置 Secrets 时，CI 自动使用仓库内固定的 `app/signing/family-fixed.keystore` 签名（与 v5.5 同证书），确保每次构建签名一致、可直接覆盖升级。
