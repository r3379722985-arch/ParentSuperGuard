# 安心超级卫士 · ParentSuperGuard

给长辈用的「一键清缓存 + 防流氓弹窗」小工具。**全程离线，不申请联网权限**，不会上传任何数据。

- 版本：v5.4（versionCode 9）
- 包名：`com.custom.parentguard`
- 适配：小米/红米（MIUI、澎湃OS）、vivo/iQOO、OPPO/一加/真我、华为/荣耀、三星、其它安卓
- 最低系统：Android 8.0（API 26）

---

## 一、它到底做了什么

| 能力 | 说明 |
| --- | --- |
| 一键清缓存 | 自动打开「应用信息 → 存储 → 清除缓存」，逐个清掉大缓存软件（抖音、拼多多、浏览器等），**只点"清除缓存"，绝不动"清除数据"** |
| 铁壁白名单 | 微信、QQ、支付宝、云闪付、数字人民币、20 家银行、医保/交管/12306/个税、相册、闹钟、输入法：**永不清缓存、永不强停、永不拦截、永不建议卸载** |
| 自定义保护 | 任何一个软件都能手动「加保护」，加了就绝不自动清理 |
| 防流氓弹窗 | 可选常驻：拦截高风险/未知来源安装包弹窗、快应用广告弹窗、疑似"领红包/极速清理"马甲乱跳 |
| 软件排查 | 列出第三方软件，标出疑似流氓马甲，可疑的一键跳系统卸载页 |
| 长辈适配 | 超大字体不裁切、按钮大、说明是大白话、微信清缓存带 3 步图文向导 |

### 会删什么、不会删什么（重要）

- **会删**：各 App 的缓存（等同于你在设置里点"清除缓存"）、`DCIM/.thumbnails` 旧缩略图、`MIUI/debug_log`、`BugReport`、`ramdump`、`diag_logs`、`vivo_log` 里的日志、以及这些目录下的空文件夹。
- **不会删**：照片、视频、聊天记录、微信目录、任何"应用数据"、任何银行/支付相关文件。

### 隐私

- `AndroidManifest.xml` 里**没有 `INTERNET` 权限**——想联网也联不了，不存在上传。
- 清缓存用的无障碍服务在系统里被限定为**只在「设置 / 安全中心」这类页面响应**（`android:packageNames`），不监听微信、银行、相册里的内容。
- 不申请通知、不申请定位、不读通讯录。

## 二、给子女：首次配置（5 分钟，只做一次）

1. **安装**：从 [Releases](../../releases) 或 Actions 的 Artifacts 下载 `ParentSuperGuard-v5.4.apk`，传到手机安装（允许"安装未知应用"）。
2. **开统计权限**：打开 App → 点「去开启使用情况权限」→ 找到「安心超级卫士」→ 允许。开完才能按缓存大小排序，只清大缓存。
3. **开清缓存无障碍**：点「一键安全清理」→ 按提示跳到无障碍设置 → 开启「安心卫士 · 自动清缓存（清完即关）」。
   - 小米/vivo 如果开关是灰的（"受限设置"），按 App 里那张蓝色卡片的 2 步解锁：应用信息 → 右上角 ⋮ → 允许受限设置 → 验证锁屏密码。
4. **（可选）防流氓**：需要常驻再开「安心卫士 · 防流氓弹窗守护」。不想常驻，就用卡片里那个「直达系统安装未知应用」按钮，把浏览器/抖音/头条的安装权限关掉，从源头挡住。
5. **（可选）文件清理**：底部按钮授权"所有文件访问"，用来清旧缩略图和系统日志。

> **银行风控提示**：`清完自动关闭无障碍`默认开启，清理结束 650ms 后服务会自己 `disableSelf()`，避免银行/云闪付检测到常驻无障碍。

### 更新版本时

构建产物是 **debug 签名**，每次 CI 构建的签名可能不同，覆盖安装会报「应用未安装」。遇到就先卸载再装（自定义保护名单会清空）。想让更新能直接覆盖，见「已知限制」。

## 三、给家长：日常怎么用

- **手机卡了/空间不足**：打开「安心超级卫士」，点最大的绿色按钮 → 等它自己翻页，翻完会跳出"清理完成，腾出 xx GB"。
- **想停**：清理过程中点「停止自动清理」。
- **孩子要给你装软件**：点「暂停 10 分钟」，装完自动恢复。
- **微信占空间**：点「看 3 步清微信」，只点绿色的【清理】按钮，照片和聊天一条都不会少。
- **看到奇怪的弹窗**：不用管，被挡掉的次数会显示在首页「已挡流氓弹窗」。

## 四、自己构建

### GitHub Actions（推荐）

推到 `main` / `master` 或打 `v*` 标签自动构建；打标签会额外发布到 Releases。

```bash
git tag v5.4 && git push origin v5.4
```

产物：Actions → 对应 run → Artifacts → `ParentSuperGuard-v5.4-APK`。

### 本地

需要 JDK 17 + Android SDK 34。仓库没有带 Gradle Wrapper，用系统 Gradle 8.7：

```bash
gradle testDebugUnitTest assembleDebug
```

单测覆盖白名单误匹配（`goodtime` 不该命中 `ime`）和弹窗安全判定（背景"应用信息"页含"卸载"二字不能误判成危险弹窗）。

## 五、已知限制

- **签名**：CI 用 debug 签名，跨次构建签名不稳定 → 覆盖升级会失败。要稳定升级，可以（A）把固定 keystore 放进仓库并配置 `signingConfig`，或（B）用 GitHub Secrets 存 keystore、改为 `assembleRelease`。
- **无「使用情况权限」时**，目前会对所有第三方软件排队清理（会翻很多页）。建议先开权限。
- 「顺便强停后台」默认关闭：开启后会在清理时强制停止应用，个别 App 可能要求重新登录。
- 只做"清缓存"，不做深度清理（不碰 `/Android/data` 里的私有数据）。
