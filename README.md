# 🛡️ 安心超级卫士（ParentSuperGuard v7.1 开源版）

> **免 Root · 免 Shizuku · 零联网无广告 · 铁壁保护微信/银行/相册 · 长辈极简与子女管理双模式**

专为父母长辈的日常非 Root 安卓手机（重点适配**小米/红米澎湃OS、vivo/iQOO OriginOS、OPPO ColorOS、华为/荣耀、三星**）打造的开源本地安全与清理工具。

---

## ✨ 为什么做这个开源项目？

市面上很多清理软件要么满屏广告诱导下载流氓马甲，要么需要 Root / Shizuku（重启失效、长辈根本不会弄），还容易误删微信聊天或触发银行 App 无障碍风控。

**安心超级卫士 v7.1** 把开源社区里经过验证的最佳实践整合进一个不到 5 MB 的离线应用里：

| 核心特性 | 设计说明 |
| :--- | :--- |
| **🏠 长辈极简主页 + 🔧 子女管理中心** | 首页只给家长留**一键安全清理、3步清微信、防偷偷扣费排查、清理历史**；复杂开关、软件排查与权限配置全部收纳在「子女管理」页，支持**可选 4 位数字管理锁**防止长辈误触乱改。 |
| **🧭 一站式权限配置中心** | 首次打开自动弹出统一权限窗口，底部一颗智能按钮顺次带你点完所有权限，开完按返回自动打勾推进，告别满屏找权限。 |
| **🛡️ 铁壁双层白名单** | 第一层（微信/QQ/企业微信/钉钉/支付宝/云闪付/数字人民币/国家反诈中心/各大银行与农商行/医保/相册/输入法/闹钟）**绝对不碰**；第二层（抖音/快手/拼多多/淘宝/小红书/B站等）**绝不当流氓拦，但允许安全清缓存**。 |
| **🏦 防银行 App 无障碍风控** | 清缓存专用无障碍服务仅监听系统设置包名，默认**清理完毕立刻自动调用 `disableSelf()` 彻底关闭**，长辈打开手机银行与云闪付不弹安全警告。 |
| **🔕 通知栏垃圾大扫除** | 自动过滤微信/银行/反诈/电话等重要软件，一键直达其余第三方软件的系统通知开关页，30 秒关光“领现金/假中奖”垃圾推送。 |
| **💸 防偷偷扣费 3 步向导** | 大字图文 + 一键打开微信/支付宝，帮家长定期排查关闭误点的“1分钱保险/短剧会员自动续费”。 |
| **✅ 子女 3 分钟防坑体检清单** | 可勾选持久化备忘 + 系统设置直达：关未知来源安装、息屏调 2 分钟、锁桌面布局、关摇一摇动作权限、免费拦截境外诈骗来电。 |
| **🔒 物理级零联网** | `AndroidManifest.xml` 彻底不申请 `INTERNET` 权限，开源代码透明可审计，永远无广告、无数据上传。 |

## 📱 使用指南

### 给长辈（平时只需 1 步）
1. 打开桌面绿色盾牌 **「安心超级卫士」**。
2. 点首页超大绿色按钮 **「一键安全清理高缓存软件」**，等半分钟看到释放空间提示即可。

### 给子女（首次部署约 2 分钟）
1. 首次打开自动进入 **「一站式权限配置中心」**，跟着底部大按钮依次开启「使用情况权限」→（Android 13+ 解锁受限设置）→「自动清缓存无障碍」。
2. 切到底部 **「子女管理」** 页：
   * 顺着 **「3 分钟防坑体检清单」** 关掉浏览器/短视频的安装未知应用权限、把息屏时间调到 2 分钟；
   * 点开 **「关垃圾推送」** 关掉拼多多/头条/浏览器等广告通知；
   * 点开 **「已装软件排查」** 确认家长手机上的所有银行 App 均显示「铁壁保护」，顺手卸载疑似流氓马甲；
   * 按需开启 **「4 位子女管理锁」**，防止家长误点修改设置。

## 🚀 GitHub 自动构建与开源签名说明

本项目自带 GitHub Actions 工作流（`.github/workflows/build-super-apk.yml`）：
* 推送 `main` 分支自动执行 `gradle testDebugUnitTest assembleRelease` 跑安全单测并产出签名 APK（在 **Actions → Artifacts** 下载）；
* 推送版本标签（例如 `git tag v7.1 && git push origin v7.1`）自动在右侧 **Releases** 发布 `ParentSuperGuard-v7.1.apk`。

### 配置私有发布签名（长期开源强烈建议）
在 GitHub 仓库 `Settings → Secrets and variables → Actions` 配置以下 4 项后，删掉仓库内兜底证书 `app/signing/family-fixed.keystore` 即可：
* `SIGNING_KEY_BASE64`（私有 `.jks` 证书的 Base64 文本）
* `SIGNING_STORE_PASSWORD`
* `SIGNING_KEY_ALIAS`
* `SIGNING_KEY_PASSWORD`
